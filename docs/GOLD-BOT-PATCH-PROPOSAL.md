**التاريخ:** 2026-10-31 · **الحالة:** proposal — ⛔ لم يُطبَّق على `gold-signal-bot` بعد.
**المرجع:** التشخيص المُقيس (انظر «التشخيص»).

## التشخيص (مقيس — مش تخمين)

المحرك **حيّ** (نبضة كل دقيقة · `m1` بيزيد) لكن **الشموع بتتموت**:
آخر شمعة في `history.json` = `2026-10-30T18:15` (١٨ ساعة قديمة) و`m15 = 8` (محتاج ٤٠).

**السبب — ثلاث حلقات منفصلة:**
1. المحرك بيخزّن الشموع في **الذاكرة + ملف محلي** (`state.bars` → `HISTORY_FILE`).
2. النبضة (`pushHeartbeat`) بتبعت **العدّاد فقط** (`bars: {m1, m15}`) — **مش الشموع نفسها** ⇒ الشموع مش بتخرج من الحاوية.
3. سكربت الـkeepalive بيشتغل في **حاوية تانية** ⇒ بيقرأ النسخة المحلية عنده (هي بسخة **مسترجَعة قديمة** من KV) ⇒ وبيرفعها تاني ⇒ **يدفن أي تحديث**.

⇒ الـengine والـkeepalive في **حاويتين مختلفتين** ⇒ الشموع الحية عمرها ما بتوصل لـKV.

**ليه قلّلنا الجدول م capita؟** قلّل الـwrites (٨٠٠+ ← ٨٥/يوم) فالسقف رجع شغّال — بس ده **مش** سبب دفء البوت. سبب الدفء **فصل المخزن عن المخزن**، وده اللي التصليح ده بيعالجه.

## التصليح: ٣ تعديلات صغيرة (مفيش binding جديد، مفيش تغيير في إعدادات)

### ١) `worker/index.js` (الـbus worker) — مسار جديد يستقبل الشموع
```js
// بعد handler الـ/heartbeat
if (url.pathname === '/bars' && req.method === 'POST') {
  const body = await req.json();
  await env.BUS.put('history.json', JSON.stringify(body));   // ⛔ من غير expirationTtl (دائم)
  return json({ ok: true });
}
```
⚠️ مهم: `expirationTtl` على `/heartbeat` = ٣٠٠ ثانية، فمينفعش نخزن فيه.

### ٢) `src/bus.js` — دالة دفع واحدة
```js
export async function pushBars(bars) { return post('/bars', { bars }); }
```

### ③) `src/index.js` — ادفع الشموع كل ١٠ دقايق
```js
import { pushSignal, pushHeartbeat, pullAccount, pushBars } from './bus.js';
// ...
setInterval(() => {
  const keys = Object.keys(state.bars).sort();
  const keep = {};
  for (const k of keys.slice(-8000)) keep[k] = state.bars[k];
  pushBars(keep).catch(() => {});
}, 600000);   // ١٠ دقايق ⇒ ١٤٤ كتابة/يوم (داخل السقف)
```

### ٤) `scripts/keepalive.sh` — استرجع `history.json` من namespace الـBUS
```sh
CF_NS="${CF_NS:-f39b746eed6c4671959bc710d82fcbc1}"          # الحالة (state · journal · outcomes)
CF_NS_BUS="${CF_NS_BUS:-3be4337a49da4153b0a8dc5122bce794}"  # الشموع (history.json)
# في restore_state: history.json يُقرأ من CF_NS_BUS والباقي من CF_NS
# في sync_state:(history.json ما يُرفعش تاني — المحرك هو اللي بيدفعه دلوقتي)
```

## النتيجة المتوقعة (متحقَّق منها رياضياً)
| البند | قبل | بعد |
|---|---|---|
| مصدر الشموع | ملف محلي في حاوية المحرك | KV دائم (namespace BUS) |
| الاسترجاع | نسخة قديمة | آخر ١٠ دقايق ⇒ **فقد ≤ ١٠ دقايق عند الموت** |
| كتابات/يوم | ٨٠٠+ | ≈ ١٤٤ (شموع) + ٨٥ (سكربت) = **≈ ٢٣٠** (داخل السقف ١٠٠٠) |
| `m15` | ٨ (ثابت) | **بيزيد ساعةً بساعة** ⇒ ٤٠ خلال ≈ ١٠ ساعات تشغيل متصل |
| `warm` | false | **true** ⇒ البوت جاهز لأول نافذة |
